Motion Prompt #111

含义：高反差边缘出现红蓝紫色边
示例效果：街景分成红绿蓝以不同倍率重合，人物与建筑出现红青边，越靠两侧越大。
效果规格：
- 场景 2：街角，建筑、树和路灯（x = 114、292、494）位于 y = 132–162 的道路后；左前人物脚位 (176, 200)，高 124px。
- 图像分别与红 #FF0000、绿 #00FF00、蓝 #0000FF 相乘成三份，在黑底上相加。
- 以中心缩放：红 1 + 2s、绿 1 + s、蓝 1，s 从 0→0.02。
- 左右边缘红蓝相差约 11px，中心为 0。
- 时间：0.4–1.4 秒效果渐入，保持至 4.0 秒，4.8 秒前消失；每轮 5 秒，三次方缓入缓出，约 cubic-bezier(0.65,0,0.35,1)。
适用场景：适合老镜头、VHS 或故障感的不完美质感。
