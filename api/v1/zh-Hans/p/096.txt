Motion Prompt #096

含义：元素轻柔地上下浮动
示例效果：标题旁手机、心形徽章和评分标签错峰浮动，手机阴影同步变化。
效果规格：
- 手机 92×132，y = −8·sin(2πt/2.4)，每 2.4 秒浮动一次，正弦在两端减速。
- 心形徽章半径 20，y = −6·sin(2πt/1.6 + 1.2)；评分标签 76×30，y = −6·sin(2πt/2.4 + 2.4)。
- 手机下方阴影为 54×6 椭圆，尺寸和透明度乘以 (1 + y/40)，手机越高阴影越小越淡。
- 周期 2.4 秒和 1.6 秒均整除 4.8 秒，循环无接缝。
适用场景：适合产品图、应用模型或装饰图标的轻柔运动。
