请使用“光标跟随（Cursor follower）”，它是“落地页与网页动效”中的一个术语。
Motion Prompt #083

含义：图形略有延迟地跟随鼠标
示例效果：鼠标移动时橙圆稍落后地跟随。
效果规格：
- 光标路径 x = 255 + 175·sin(2πt/4.8)，y = 86 + 46·sin(4πt/4.8)，横向 8 字，每 4.8 秒一圈。
- 橙圆半径 17、透明度 0.88，位于光标下层。
- 60fps 下每帧走剩余距离的 12%，x += (cursor x − x) × 0.12。
- 箭头光标保持可见。
适用场景：适合品牌站和作品集的互动趣味。
