Motion Prompt #010

含义：略微超过目标位置，再回到目标
示例效果：仪表指针越过目标，回摆并停稳。
效果规格：
- 每 4.7 秒一轮。半圆仪表半径 128、描边 26。目标在全程的 0.7，即从左端起 126°。
- 0.25 秒开始：值 = 0.7 × (1 − e^(−4.6t)·cos(10.5t))。约 0.3 秒后超出目标约 25%，随后振荡回稳。
- 超过目标的区段为珊瑚色，目标用黄色刻度标记。
- 填充弧为蓝→薄荷色渐变；指针白色，宽 9。
- 从 3.7 秒复位：值 = 0.7 × e^(−7.5t)·cos(8.5t)，回到 0 前略微低于 0。
适用场景：适合让到位动作富有力量和弹性。
