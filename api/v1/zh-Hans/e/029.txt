// 跟拍 / Tracking shot
// 素材包: camera (镜头运动与转场) · element 05 · 分类: 镜头运动
// 示例效果: 相机与人物同速横移，人物居中，近处柱子更快掠过。
// 效果规格:
//   - 相机以 1.7m/s 匀速向右，4.7 秒内 x = −4→+4m，高 1.3m，正向拍摄，无缓动。
//   - 人物深度 7.5m，与相机的 x 相同，始终居中；手脚摆动 sin(u×7)×0.42rad。
//   - 视差：深度 4m、间距 1.6m 的柱子向左最快，其次树、48m 外建筑，远山几乎不动。
//   - 右上角显示“→ 1.7m/s”。
//   - 每 4.7 秒跳回起点，柱子与地面网格在接缝对齐，背景建筑和树会跳变。
// 适用场景: 适合跟随行走或奔跑主体，展示动作与移动感。
// 标签: tracking, tracking shot, follow, truck, lateral, sideways, parallax, walk
// 尺寸: 539x208 px · 循环周期: 9.4 s
// Needs: kit camera -> https://motion-prompt.knothhe.com/api/v1/kit/camera.js
// 动态示例: https://motion-prompt.knothhe.com/#029
//
// cells[i](k, w, h, u)：k 为 CanvasRenderingContext2D（调用方已清空并用 save/restore 包裹），w、h 为尺寸，u 为秒数，范围 [0, cycle)。画面仅由 u 决定。
// 以下为效果代码。CELLS、常量与辅助函数位于 kit 中。

// @element 05
// 05 トラッキング: 人物と並んで横移動（手前ほど速く流れる）
CELLS[4] = shot((k, w, h, u) => {
  const x = (u - CYC / 2) * 1.7;
  const fgp = []; for (let i = -12; i <= 12; i++) fgp.push([i * 1.6, 4]);
  world(k, w, h, cam({ x, y: 1.3 }), { person: { x, z: 7.5, walk: u * 7 }, fg: fgp });
  return '→ 1.7m/s';
});
