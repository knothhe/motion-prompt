// 滑动变焦 / Dolly zoom (Vertigo)
// 素材包: camera (镜头运动与转场) · element 08 · 分类: 镜头运动
// 示例效果: 相机后退同时变焦，人物大小不变，背景向人物靠拢。
// 效果规格:
//   - 人物位于前方 8m，相机到人物距离 d 从 3.2→8m，后退 4.8m，高 1.3m。
//   - 焦距 f = 330 × d/8px，即 132→330px，标为 10→24mm，距离 ÷ 焦距保持不变。
//   - 0.5–3.4 秒，持续 2.9 秒，三次方缓入缓出，约 cubic-bezier(0.65,0,0.35,1)。
//   - 人物静止，画面高度不变；头部高 1.8m 与脚部有宽 160px 的蓝色虚线，标记尺寸恒定。
//   - 48m 外建筑约放大 2.2 倍，山约 2.4 倍，背景逼近人物，人物前的地面缩小。
//   - 3.4–4.2 秒停留，最后 0.5 秒交叉淡化复位，每轮 4.7 秒。
// 适用场景: 适合表现顿悟、不安或震惊。
// 标签: dolly zoom, vertigo, zolly, push pull, background stretch, unease, camera move
// 尺寸: 539x208 px · 循环周期: 9.4 s
// Needs: kit camera -> https://motion-prompt.knothhe.com/api/v1/kit/camera.js
// 动态示例: https://motion-prompt.knothhe.com/#032
//
// cells[i](k, w, h, u)：k 为 CanvasRenderingContext2D（调用方已清空并用 save/restore 包裹），w、h 为尺寸，u 为秒数，范围 [0, cycle)。画面仅由 u 决定。
// 以下为效果代码。CELLS、常量与辅助函数位于 kit 中。

// @element 08
// 08 ドリーズーム: 人物の大きさは一定、背景だけ伸び縮み
CELLS[7] = shot(camCell((k, w, h, p) => {
  const d = lerp(3.2, 8, p), f = F0 * d / 8 * 1.0;
  const c = cam({ z: 8 - d, f, y: 1.3 });
  world(k, w, h, c, {
    person: { z: 8 }, trees: true,
    after: (kk, cc) => { const top = proj(cc, 0, 1.8, 8).y, bot = proj(cc, 0, 0, 8).y; kk.strokeStyle = C.blue; kk.lineWidth = 1.6; kk.setLineDash([6, 5]); kk.beginPath(); kk.moveTo(-80, top); kk.lineTo(80, top); kk.moveTo(-80, bot); kk.lineTo(80, bot); kk.stroke(); kk.setLineDash([]); }
  });
}, p => mm(F0 * lerp(3.2, 8, p) / 8)));
