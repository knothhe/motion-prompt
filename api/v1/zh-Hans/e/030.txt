// 环绕镜头 / Orbit (Arc shot)
// 素材包: camera (镜头运动与转场) · element 06 · 分类: 镜头运动
// 示例效果: 相机绕人物移动，人物居中，背景树与建筑横向掠过。
// 效果规格:
//   - 相机以人物为中心绕半径 6m 的圆运动，人物原位于前方 9m；角度 −0.95→+0.95rad，即 −54°→+54°，约 109°。
//   - 始终朝向圆心，偏航 = −角度，高 1.7m，俯仰固定 −0.07rad，约向下 4°。
//   - 0.5–3.6 秒，持续 3.1 秒，三次方缓入缓出，约 cubic-bezier(0.65,0,0.35,1)。
//   - 人物不动，脸上的白点随角度横移，地面有半径 1.3m 的虚线圆。
//   - 12 棵树等距位于半径 10m 的圆上，随环绕从人物后方穿过。
//   - 3.6–4.2 秒停留，最后 0.5 秒交叉淡化复位；右上角显示 −54°→+54°。
// 适用场景: 适合立体展示人物或产品，强调登场或关键时刻。
// 标签: orbit, arc shot, circle, 360, rotate around, revolve, camera move
// 尺寸: 539x208 px · 循环周期: 9.4 s
// Needs: kit camera -> https://motion-prompt.knothhe.com/api/v1/kit/camera.js
// 动态示例: https://motion-prompt.knothhe.com/#030
//
// cells[i](k, w, h, u)：k 为 CanvasRenderingContext2D（调用方已清空并用 save/restore 包裹），w、h 为尺寸，u 为秒数，范围 [0, cycle)。画面仅由 u 决定。
// 以下为效果代码。CELLS、常量与辅助函数位于 kit 中。

// @element 06
// 06 オービット: 被写体を中心に円を描いて回り込む
CELLS[5] = shot(camCell((k, w, h, p) => {
  const a = lerp(-0.95, 0.95, p), R = 6, P0 = [0, 0, 9];
  const c = cam({ x: P0[0] + Math.sin(a) * R, z: P0[2] - Math.cos(a) * R, yaw: -a, y: 1.7, pitch: -0.07 });
  world(k, w, h, c, {
    person: { z: 9, face: a }, ring: [0, 9, 10], buildings: true, trees: false,
    after: (kk, cc) => { kk.strokeStyle = C.blueM; kk.lineWidth = 2; kk.setLineDash([5, 5]); kk.beginPath(); for (let i = 0; i <= 48; i++) { const b = i / 48 * Math.PI * 2; const q = proj(cc, Math.sin(b) * 1.3, 0, 9 + Math.cos(b) * 1.3); i ? kk.lineTo(q.x, q.y) : kk.moveTo(q.x, q.y); } kk.stroke(); kk.setLineDash([]); }
  });
}, p => `${Math.round(lerp(-0.95, 0.95, p) * 57.3)}°`.replace(/^(\d)/, '+$1'), 0.5, 3.6));
