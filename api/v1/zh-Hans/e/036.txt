// 荷兰角 / Dutch angle
// 素材包: camera (镜头运动与转场) · element 12 · 分类: 拍摄风格与时间
// 示例效果: 相机绕镜头轴旋转，让地平线斜置并保持。
// 效果规格:
//   - 机位固定，高 1.5m，仅侧倾 0→0.36rad，约 21°，整幅画面绕中心旋转。
//   - 0.6–2.2 秒，持续 1.6 秒，三次方缓入缓出，约 cubic-bezier(0.65,0,0.35,1)。
//   - 人物静止于前方 7m，地平线、建筑和人物同步倾斜。
//   - 2.2–4.2 秒保持倾斜，留时间观看构图。
//   - 最后 0.5 秒交叉淡化回水平起点，每轮 4.7 秒。
//   - 右上角显示 ∠0°→∠21°。
// 适用场景: 适合不安、紧张或失衡感。
// 标签: dutch angle, dutch tilt, canted angle, oblique, roll, tension, tilted horizon
// 尺寸: 539x208 px · 循环周期: 9.4 s
// Needs: kit camera -> https://motion-prompt.knothhe.com/api/v1/kit/camera.js

// cells[i](k, w, h, u)：k 为 CanvasRenderingContext2D（调用方已清空并用 save/restore 包裹），w、h 为尺寸，u 为秒数，范围 [0, cycle)。画面仅由 u 决定。
