// 垂直摇镜 / Tilt
// 素材包: camera (镜头运动与转场) · element 02 · 分类: 镜头运动
// 示例效果: 镜头原地向上转，从地面人物移向塔顶。
// 效果规格:
//   - 机位固定，高 1.4m，仅俯仰 −0.06→+0.36rad，即 −3°→+21°，总计约 24°。
//   - 0.5–3.4 秒，持续 2.9 秒，三次方缓入缓出，约 cubic-bezier(0.65,0,0.35,1)。
//   - 人物位于前方 7m；后方 26m 的塔高 9.5m，天线顶端高 11.8m。
//   - 画面中的物体向下移动，人物从底部离开，塔顶与天线进入画面。
//   - 3.4–4.2 秒停留，最后 0.5 秒交叉淡化复位，每轮 4.7 秒。
//   - 右上角以整数显示角度 −3°→+21°。
// 适用场景: 适合展示建筑或人物的高度和尺度。
// 标签: tilt, tilt up, pitch, vertical, look up, camera move
// 尺寸: 539x208 px · 循环周期: 9.4 s
// Needs: kit camera -> https://motion-prompt.knothhe.com/api/v1/kit/camera.js
// 动态示例: https://motion-prompt.knothhe.com/#026
//
// cells[i](k, w, h, u)：k 为 CanvasRenderingContext2D（调用方已清空并用 save/restore 包裹），w、h 为尺寸，u 为秒数，范围 [0, cycle)。画面仅由 u 决定。
// 以下为效果代码。CELLS、常量与辅助函数位于 kit 中。

// @element 02
// 02 ティルト
CELLS[1] = shot(camCell((k, w, h, p) => world(k, w, h, cam({ pitch: lerp(-0.06, 0.36, p), y: 1.4 }), { person: { z: 7 }, tower: [0, 26], buildings: false, sun: [7, 13, 40], sunScale: 0.4 }),
  p => `${Math.round(lerp(-0.06, 0.36, p) * 57.3)}°`.replace(/^(\d)/, '+$1')));
