// 慢动作 / Slow motion
// 素材包: camera (镜头运动与转场) · element 13 · 分类: 拍摄风格与时间
// 示例效果: 固定镜头前人物缓慢起跳和落下，树叶也缓缓飘落。
// 效果规格:
//   - 相机完全固定，高 1.3m，仅主体运动。
//   - 人物距 7m，0.5–4.3 秒完成一次 3.8 秒的跳跃；高度 = 4q(1−q)×1.1m，抛物线最高 1.1m，q 随时间线性变化。
//   - 腾空时双臂上举，起跳前站立 0.5 秒，落地后站立 0.4 秒。
//   - 9 片树叶在 4.7 秒内从 3.4m 旋转落地，相位各错开周期的 1/9。
//   - 右上角显示“120fps ×0.25”，表示播放时长拉伸 4 倍。
//   - 无停留或交叉淡化，每 4.7 秒无缝循环。
// 适用场景: 适合细看瞬间动作、表情或强调情绪高潮。
// 标签: slow motion, slow-mo, slomo, high frame rate, 120fps, time stretch, jump
// 尺寸: 539x208 px · 循环周期: 9.4 s
// Needs: kit camera -> https://motion-prompt.knothhe.com/api/v1/kit/camera.js
// 动态示例: https://motion-prompt.knothhe.com/#037
//
// cells[i](k, w, h, u)：k 为 CanvasRenderingContext2D（调用方已清空并用 save/restore 包裹），w、h 为尺寸，u 为秒数，范围 [0, cycle)。画面仅由 u 决定。
// 以下为效果代码。CELLS、常量与辅助函数位于 kit 中。

// @element 13
// 13 スローモーション
CELLS[12] = shot((k, w, h, u) => {
  const q = P(u, 0.5, 4.3);
  world(k, w, h, cam({ y: 1.3 }), { person: { z: 7, y: jumpY(q), armUp: q > 0 && q < 1 }, extra: leaves(u, 1) });
  return '120fps ×0.25';
});
