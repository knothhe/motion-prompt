// 升降镜头上升 / Crane up
// 素材包: camera (镜头运动与转场) · element 07 · 分类: 镜头运动
// 示例效果: 相机上升并向下俯拍，逐渐俯视人物。
// 效果规格:
//   - 相机高度 1.4→9m，同时前移 0→1.5m。
//   - 向下俯拍前方 8m 的人物，俯仰 = −0.86 × atan2(height − 1.0, 8 − forward)，约 −2.5°→−44°。
//   - 0.5–3.4 秒，持续 2.9 秒，三次方缓入缓出，约 cubic-bezier(0.65,0,0.35,1)。
//   - 人物不动，随相机升高变小；地面网格填满画面，地平线从顶部离开。
//   - 3.4–4.2 秒停留，最后 0.5 秒交叉淡化复位，每轮 4.7 秒。
//   - 右上角显示高度 ↑1.4m→↑9.0m。
// 适用场景: 适合场景结尾远离人物，或揭示环境规模。
// 标签: crane, crane up, jib, boom up, rise, high angle, camera move
// 尺寸: 539x208 px · 循环周期: 9.4 s
// Needs: kit camera -> https://motion-prompt.knothhe.com/api/v1/kit/camera.js
// 动态示例: https://motion-prompt.knothhe.com/#031
//
// cells[i](k, w, h, u)：k 为 CanvasRenderingContext2D（调用方已清空并用 save/restore 包裹），w、h 为尺寸，u 为秒数，范围 [0, cycle)。画面仅由 u 决定。
// 以下为效果代码。CELLS、常量与辅助函数位于 kit 中。

// @element 07
// 07 クレーンアップ: カメラが上昇し、見下ろしになる
CELLS[6] = shot(camCell((k, w, h, p) => {
  const y = lerp(1.4, 9, p), z = lerp(0, 1.5, p);
  world(k, w, h, cam({ y, z, pitch: -0.86 * Math.atan2(y - 1.0, 8 - z) }), { person: { z: 8 } });
}, p => `↑ ${lerp(1.4, 9, p).toFixed(1)}m`));
