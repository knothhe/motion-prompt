// 交叉溶解 / Cross dissolve
// 素材包: camera (镜头运动与转场) · element 20 · 分类: 转场
// 示例效果: 下一画面叠加并逐渐变实，中途两幅画面彼此透出。
// 效果规格:
//   - 1.5–3.0 秒转场，共 1.5 秒，新画面透明度 0→100%。
//   - 二次方缓入缓出，约 cubic-bezier(0.45,0,0.55,1)，2.25 秒达 50%。
//   - 旧画面在下方保持完全不透明，新画面在上方绘制，不先淡出旧画面。
//   - 两个画面机位固定，A 高 1.4m，B 高 1.6m、俯仰 +0.1rad，主体均不动。
//   - 0–1.5 秒只显示旧画面，3.0–4.7 秒只显示新画面。
//   - 每 4.7 秒交替 A→B、B→A，往返 9.4 秒，右上角显示方向。
// 适用场景: 适合柔和表现时间或地点变化，也适合进入回忆。
// 标签: cross dissolve, dissolve, crossfade, fade, opacity, blend, transition
// 尺寸: 539x208 px · 循环周期: 9.4 s
// Needs: kit camera -> https://motion-prompt.knothhe.com/api/v1/kit/camera.js
// 动态示例: https://motion-prompt.knothhe.com/#044
//
// cells[i](k, w, h, u)：k 为 CanvasRenderingContext2D（调用方已清空并用 save/restore 包裹），w、h 为尺寸，u 为秒数，范围 [0, cycle)。画面仅由 u 决定。
// 以下为效果代码。CELLS、常量与辅助函数位于 kit 中。

// @element 20
// 20 クロスディゾルブ
CELLS[19] = shot(abCell((k, w, h, u, A, B) => blend(k, kk => A(kk, w, h), kk => B(kk, w, h), eIOs(P(u, 1.5, 3.0)))));
